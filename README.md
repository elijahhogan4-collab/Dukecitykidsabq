# Duke City Kids

Directory of kids' activities in Albuquerque — https://dukecitykidsabq.com

- Listings live in `data/listings.json`; categories and site settings in `data/site.json`.
- `node build.js` builds the static site into `dist/` (no dependencies).

## Deploy (Cloudflare Pages)
- Build command: `node build.js`
- Output directory: `dist`
